# DealRadar
 An app to track deals on eBay and Facebook Marketplace
 # # DealRadar
 
 DealRadar is a global deal comparison tool focused initially on **LEGO sets**, helping users find the best available offers from both second-hand and retail platforms.
 
 Users can search for a specific LEGO product and instantly view listings from marketplaces such as **eBay** and **Facebook Marketplace**, alongside retail prices from stores like **Amazon**.  
 Each result includes:
 
 - **Listing Price**  
 - **Retail Price** (with source, e.g. “Amazon” or “Bol.com”)  
 - **Deal Score** — percentage savings compared to retail  
 - **Condition** (New, Sealed, Opened)  
 - **Shipping Cost**  
 - **Total Cost** (Listing + Shipping)  
 - **Seller Location**  
 - **Source Platform** (eBay / Facebook / Amazon / etc.)  
 - **Direct Purchase Link**
 
 By showing the **retail source**, users immediately know which store’s price is used for the Deal Score calculation.

 ## Future Roadmap
 
 1. **Automated Scraping**  
    - Real-time data fetching from all integrated platforms.
 
 2. **Expand Market Coverage**  
    - Add more second-hand marketplaces (Marktplaats, eBay-regional, OfferUp).  
    - Add additional retail stores per region (Walmart, Target, Bol.com).
 
 3. **One-Click Ad Generator**  
    - Instantly generate a complete resale listing: title, description, and image suggestions—ready to copy-paste.
 
 4. **User Accounts & Favorites**  
    - Save favorite searches and products.  
    - Track price history and receive alerts.
 
 5. **Premium Features**  
    - Advanced filters and sorting (e.g. by Deal Score threshold).  
    - Real-time push notifications for new top-score deals.  
    - Historical price charts and trend analysis.
